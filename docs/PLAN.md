# План: робототехнические сборки (машинка + рука)

## Цель
Дать пользователю собирать два «стенда» — самоходную машинку и механическую
руку — подключать к их контактам Arduino и программировать теми же блоками,
что уже есть (`digital write`, `analog write`, `servo write`, `read distance`).

## Ключевые решения
- **Никаких новых блоков и нового C++-генератора.** Существующих блоков
  достаточно, потому что связь «пин Arduino → компонент» уже реализована для
  сервопривода (`runtime.servoAngle[pin]` + `engine.resolveLogicPin`).
- **Физика — чистый Dart** в `lib/engine/robotics.dart`, без Flutter-импортов:
  её можно тестировать без рендеринга.
- **Машинка ездит по полю.** Поза (`x`,`y`,`rotation`) обновляется каждый тик
  из `AppState`; провода идут за пинами, потому что `pinPosition()` учитывает
  `rotation`. Границы поля (2400×1600) работают стенами.
- **Датчик машинки — «живой».** Расстояние считается лучом до стены и
  записывается в `properties['distance']`, откуда его берёт солвер
  (`ultrasonicDistanceByEchoPin`) — поэтому `read distance` работает без правок
  солвера.

## Задачи
1. `models/component_type.dart` — типы `robotCar`, `robotArm`, их спеки (пины,
   геометрия, defaults), категория `Robotics`.
2. `engine/robotics.dart` — чистая логика: чтение команд с драйвера,
   дифференциальный привод, луч до стен, кинематика руки.
3. `engine/solver.dart` — новые типы в `break`-ветках.
4. `state/app_state.dart` — тик физики, «спавн» позы для сброса, запрет
   перетаскивания едущей машинки.
5. `ui/canvas/component_visual.dart` — скорости колёс, углы суставов, фаза колёс.
6. `ui/canvas/component_painter.dart` — отрисовка машинки (вид сверху) и руки
   (вид сбоку + индикатор базы).
7. `ui/widgets/palette.dart` — иконки и категория.
8. `ui/widgets/properties_panel.dart` — телеметрия (скорости, расстояние, углы).
9. `examples/examples.dart` — урок «объезд стен» и «рука берёт предмет».
10. Тесты: спеки/подписи, кинематика (чистые функции), прогон примеров.
11. `README.md` — раздел про роботов.

## Критерий готовности
`flutter analyze` — 0 issues, `flutter test` — всё зелёное, примеры машинки и
руки реально двигаются в симуляции (проверяется тестом на изменение позы и
углов суставов).

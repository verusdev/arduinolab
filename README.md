# Arduino Lab

Кроссплатформенная симуляция Arduino в стиле Tinkercad Circuits: размещение компонентов, проводка, блочное программирование и пошаговый симулятор.

Написано на Flutter. Работает на Windows, Web, Android, iOS.

## Возможности

- **Схема** — перетаскивайте компоненты из палитры, вращайте, соединяйте пины проводами. Свойства компонентов (сопротивление, свет, положение потенциометра, параметры датчиков) можно редактировать.
- **Блочное программирование** — программа собирается из блоков, разделена на `setup` и `loop` (пины, задержки, циклы, условия, переменные, Serial, сервопривод, зуммер, LCD, датчики).
- **Два представления программы** — одно и то же блочное дерево:
  - `SketchPrinter` — превью Arduino C++ (только для чтения)
  - `SketchCompiler` — компиляция в байткод встроенной ВМ
- **Живая симуляция** — модифицированный MNA-солвер считает напряжения в узлах каждый кадр. Горят светодиоды, крутится сервопривод, работает Serial Monitor, датчики (HC-SR04, DHT11) возвращают значения в программу.
- **Сохранение/загрузка** — через `shared_preferences` (слоты) и импорт/экспорт JSON.
- **Готовые уроки** — 8 примеров: Blink, Кнопка+светодиод, Потенциометр+светодиод, Сервопривод, Пьезо-зуммер, LCD 16x2, Ультразвуковой дальномер, DHT11.
- **Адаптивный UI** — на десктопе/web 3 колонки, на телефоне — вкладки.

## Запуск

```sh
flutter pub get
flutter run -d windows  # или chrome, android, ios
```

## Архитектура

```
lib/
  blocks/            блоки, каталог, превью C++
  engine/            netlist, solver, vm, simulation_engine
  models/            circuit, pins, component specs, project
  examples/          готовые уроки
  services/          хранение JSON
  state/             AppState (ChangeNotifier)
  ui/                тема, канвас, виджеты
  main.dart
```

Ядро (`models/`, `engine/`) не зависит от Flutter — легко тестируется.

## Как играть

1. **Examples & lessons** → выберите урок → **Load this example**
2. **Run** — запустить симуляцию, **Stop** — остановить, **Reset** — сбросить
3. Вкладки: **Blocks**, **Sketch**, **Serial**, **Inspector**

## Особенности симуляции

- Виртуальное время в микросекундах; `delay()` «перепрыгивает» вперёд.
- Кооперативный режим: ВМ работает с бюджетом инструкций за кадр — бесконечный цикл не зависнет.
- Светодиод моделируется как 180 Ом, `INPUT_PULLUP` — 40 кОм к 5 В, выходные пины — фиксированное напряжение.
- Эмуляция `pulseIn()`/DHT11 через связи по электрическим узлам (netlist).
